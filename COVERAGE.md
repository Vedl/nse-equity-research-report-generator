## What each outcome means

- **OK** — profile resolved and all 12 core fields present.
- **PARTIAL** — profile resolved; some core fields legitimately absent
  (e.g. banks/NBFCs don't report `current_liabilities`, `inventory`, or
  `capital_expenditure`). The pipeline degrades these sections gracefully —
  they do **not** fail the report.
- **NO_DATA** — the `.NS` symbol does not resolve on yfinance (no coverage).
- **EMPTY / ERROR** — statements all empty / fetch raised after retries.

## NO_DATA — 48 names still failing, and why

None are code defects. After removing 4 bogus `DUMMYVEDL*` placeholder symbols
(NSE Vedanta-demerger dummies), the remainder fall into two groups:

- **~44 recent 2024–2025 IPOs / demergers** (SWIGGY, MEESHO, HYUNDAI, NTPCGREEN,
  TATACAP, HDBFS, ITCHOTELS, JSWCEMENT, TMCV…) — yfinance has no financial
  history for them yet.
- **A few long-listed companies that were renamed** (UNITDSPR, AEGISLOG,
  HBLENGINE, TARIL) whose history lives under a legacy Yahoo symbol. The
  `_SYMBOL_OVERRIDES` map handles these (e.g. `UNITDSPR → MCDOWELL-N`); in this

## Fixes applied

1. **Retry/backoff on transient failures** (`_with_retries` in
   `yfinance_provider.py`) — exponential backoff + jitter on rate-limits /
   timeouts; empty/sparse payloads (yfinance's rate-limit tell) are retried
   then degrade gracefully. Result: 0 ERROR across the full sweep.
2. **Removed 4 `DUMMYVEDL*` placeholder symbols** from the universe and ticker
   CSV — bad data that could never resolve (universe is now a clean 500).
3. **Symbol-override map** (`_SYMBOL_OVERRIDES`) for NSE→Yahoo renames
   (e.g. United Spirits `UNITDSPR` → `MCDOWELL-N`), applied in `_normalize_ticker`.
4. **Graceful sparse-data handling** — PARTIAL names render with the missing
   sections marked unavailable instead of failing (reinforced by the BUG 1
   per-stage isolation).
